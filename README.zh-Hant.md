# 以太坊巨鯨是聰明錢嗎？鏈上訊號與市場情緒的事件研究

大型以太坊轉帳若被視為單一類別，預測力很弱；但把交易依照資金流入或流出已標記交易所來區分後，會出現一個可衡量的不對稱現象：**交易所存入之後的下跌比例略高於相同市場條件下的基準，而交易所提領在後期樣本中沒有維持穩定的上漲關聯。**

本研究分析 2023 年 1 月至 2026 年 7 月間 646,442 筆成功、金額超過 100 萬美元的以太坊頂層交易。我以公開地址標籤分類交易，配對每小時 ETH 價格與兩項市場情緒指標，再與相同條件下所有合資格時段的報酬方向比較。

## 主要發現

- **交易所存入包含溫和但可重複觀察的訊號。** 24 小時後價格下跌的命中率為 50.45%，比配對後的下跌基準高 1.33 個百分點。結果在 100 萬至 1,000 萬美元門檻之間相近，並在 2024、2025 與 2026 年部分樣本中逐年增大。
- **早期有效的提領條件沒有持續。** 負資金費率期間的提領優勢在 2023 年為 +4.71 個百分點、2024 年為 +10.12；2025 年降至 +0.07，2026 年部分樣本則為 −3.92。
- **存入關聯在較長時間跨度更大，但推論更困難。** 六個月時差異達 +12.44 個百分點，但大量事件共用相同的未來價格區間，獨立資訊遠少於交易筆數。最大不利變動也顯示，即使最後方向正確，中途仍可能大幅反向移動。

這些結果是關聯，不代表轉帳造成價格變動，也不能證明持有人確實打算交易。交易所流向只是代理變數，本研究亦不是即時、已計入成本的交易策略。但結論並非「巨鯨完全沒有資訊」，而是**交易規模本身不如資金流向有用**。

## 研究問題與範圍

> 超過 100 萬美元的以太坊交易，是否與後續 ETH 報酬方向有關？市場情緒是否會改變這項關聯？

分析涵蓋四個最低交易門檻（100 萬、200 萬、500 萬與 1,000 萬美元）、八個主要報酬時間跨度（1 小時、6 小時、24 小時、3 天、1 週、1 個月、3 個月與 6 個月）、年度子樣本、七種情緒條件，以及規則式牛熊市場劃分。回撤分析另包含兩週跨度。

專案包含兩個彼此分開的分析部分：

- **主要事件研究**只使用已知地址標籤直接判定的類別。未知地址之間的轉帳不會進入存入與提領測試。
- **Random Forest 原型**另行測試簡單交易特徵能否重建規則類別。模型在已由地址規則標記的留出資料上達到 67.7% 準確率；把它套用到未知地址屬於探索性用途，沒有可獨立驗證的真實標籤，其預測不會進入本文的事件研究結果。

這項區分很重要：若把模型預測的交易所類別加入主要分析，金融結果會同時包含分類誤差；目前的事件研究則可直接理解為對一組明確地址規則的測試。

## 操作定義

### 巨鯨交易與交易類別

「巨鯨交易」是當時美元價值嚴格高於指定門檻的成功頂層交易。它只是金額篩選，不代表地址一定屬於富有個人；交易所營運、託管機構、合約與自動化參與者都可能符合條件。

類別規則依序套用，第一個符合者優先：

1. 接收方標記為 `exchange` → **交易所存入**。
2. 發送方標記為 `exchange` → **交易所提領**。
3. 任一方標記為 `defi` → **DeFi 互動**。
4. 其餘 → **錢包對錢包**。

因此交易所對交易所的轉帳會被算作存入。`wallet_to_wallet` 包含未知地址與其他未匹配類別，不能理解為已確認的個人錢包活動。主要存入與提領結果只使用前兩個規則類別。

MEV 候選交易透過少量已知地址與交易特徵標記，但不直接刪除，以便進行敏感度分析。此標記不可能涵蓋所有 MEV 活動。

### 命中率與配對基準

對交易所存入而言，「命中」代表未來指定時間的 ETH 價格較低；對提領而言，則代表價格較高。存入只是潛在賣出意圖的代理，提領也只是潛在累積的代理，兩者都沒有觀察到實際成交或持有人的動機。

ETH 可能長期處於單一趨勢，因此只看命中率會誤導。本研究報告：

```text
優勢（百分點）＝巨鯨事件命中率 − 配對後的每小時市場基準率
```

當結果依年度或情緒條件分組時，基準率亦使用相同年度、條件與方向。例如，極度貪婪時的 54% 存入命中率，應與所有極度貪婪時段之後的下跌比例比較，而不是固定與 50% 比較。這項調整控制該市場狀態本來常見的方向，但不會使相鄰的巨鯨事件變成獨立觀測。

### 情緒與市場狀態

恐懼與貪婪指數分為極度恐懼（≤25）、恐懼（25–45）、中性（45–55）、貪婪（55–75）與極度貪婪（>75）；資金費率以零為界。它們只用來為事件研究分組，不被視為獨立預測模型。

恐懼與貪婪指數是每日資料，專案以日曆日期合併，因此該數值不一定在每個 UTC 日開始時已公布。在未建模實際發布時間前，相關條件結果需要保守解讀。

牛熊市場使用 20% 高低點規則。完整樣本產生 27 個交替區段，而不是把整個年度指定為單一狀態。新聞標題的 VADER 分數屬於另一項實驗；新聞情緒作為價格特徵時表現很弱，並未進入主要結果。VADER 是詞典規則法，不是本專案訓練的模型。

## 方法

處理流程如下：

1. 從 Dune 載入大型交易，標準化地址並合併地址標籤。
2. 標記 MEV 候選，依上述規則建立交易類別。
3. 合併每小時價格、資金費率與每日恐懼與貪婪指數。
4. 計算各時間跨度的未來 ETH 報酬。
5. 計算存入與提領命中率，再減去相應的市場基準。
6. 依年度、門檻、情緒與牛熊狀態重複分析。

已提交的 [`app/dashboard_data.json`](app/dashboard_data.json) 是線上儀表板使用的彙總資料；[`results/`](results/) 中的小型 CSV 只是從同一 JSON 擷取較容易閱讀的結果，不是對原始事件研究的獨立重現。

年度表屬於描述性子樣本，不是嚴格意義下的四次獨立實驗。主要解讀在處理 2023–2025 資料時形成，2026 資料之後才加入，且沒有更改參數。因此 2026 可作為後期樣本檢查，但它只有部分年度，並沿用相同標籤與分析選擇，不能視為絕對確認。

## 結果：不對稱的交易所資金流訊號

### 存入呈現溫和的 24 小時關聯，長時間跨度差異更大

| 時間跨度 | 存入相對配對基準的優勢 |
|---|---:|
| 1 小時 | +0.11 個百分點 |
| 6 小時 | −0.05 個百分點 |
| 24 小時 | +1.33 個百分點 |
| 3 天 | +1.36 個百分點 |
| 1 週 | +1.61 個百分點 |
| 1 個月 | +4.79 個百分點 |
| 3 個月 | +8.05 個百分點 |
| 6 個月 | +12.44 個百分點 |

來源：[`results/published_horizon_edges.csv`](results/published_horizon_edges.csv)。

24 小時存入命中率為 50.45%，配對後下跌基準為 49.12%，差異為 1.33 個百分點。這代表在本樣本中，已標記的交易所存入之後出現下跌的比例略高於所有合資格時段；6 小時沒有同方向差異，較長時間跨度則逐步增大。

長時間跨度的增加不能證明存入者能預測六個月後的市場。許多事件重複計算相同價格走勢，交易筆數大幅高估真正獨立的資訊量；這是一項描述性比較，不是單調因果效果的證據。

### 提領失去早期的條件關聯

| 年度 | 存入優勢 | 負資金費率提領優勢 |
|---|---:|---:|
| 2023 | −0.17 | +4.71 |
| 2024 | +0.88 | +10.12 |
| 2025 | +1.79 | +0.07 |
| 2026（截至 7 月） | +3.86 | −3.92 |

以上單位皆為百分點。來源：[`results/published_yearly_edges.csv`](results/published_yearly_edges.csv)。

存入差異在 2024–2026 年為正，且 2026 部分樣本較大；負資金費率下的提領差異在 2023–2024 年為正、2025 年接近零、2026 年轉負。這顯示「提領代表看漲累積」並不是穩定代理。

質押、流動性供應、跨鏈橋與託管調整可能改變提領的經濟含義，但本專案沒有追蹤提領後的資金去向，因此無法證實 DeFi 是原因。門檻分析只能排除「變化只出現在 1,000 萬美元以下」這個狹窄說法。

### 交易規模敏感度

| 最低規模 | 存入命中率 | 優勢 |
|---|---:|---:|
| $1M | 50.45% | +1.33 |
| $2M | 50.54% | +1.42 |
| $5M | 50.35% | +1.23 |
| $10M | 50.48% | +1.35 |

優勢單位為百分點。四個門檻的結果相近，表示 24 小時結果不是由單一美元切點造成；但它也不表示交易越大，效果越強。條件式門檻結果位於 [`results/published_threshold_sensitivity.csv`](results/published_threshold_sensitivity.csv)。固定美元門檻的經濟意義亦會隨 ETH 價格改變。

### 情緒條件

在 24 小時、100 萬美元門檻下，極度貪婪期間的存入命中率為 54.43%，配對後下跌基準為 51.78%，差異 +2.65 個百分點。負資金費率期間的提領上漲命中率為 55.14%，但配對基準更高（56.43%），因此差異為 −1.29。

這說明高命中率本身不足以建立訊號：條件可能只是挑出本來就常向同一方向移動的時段。情緒變數在此是控制與分組工具，不代表情緒造成後續價格變化。

### 牛熊市場

|---|---:|---:|---:|---:|
| $1M | +0.46 | +3.92 | −1.21 | −3.95 |
| $2M | +0.66 | +4.83 | −1.78 | −4.30 |
| $5M | +1.53 | +4.92 | −4.19 | −6.14 |
| $10M | +2.17 | +4.61 | −3.14 | −7.69 |

表中為一週跨度、單位為百分點。來源：[`results/published_bull_bear.csv`](results/published_bull_bear.csv)。四個門檻下，熊市的存入差異均較大，熊市的提領差異也更負。不過市場狀態由同一價格路徑建構，事件窗口仍有重疊，因此這只是條件描述，不是可交易的狀態模型。

| 2 週 | 95,088 | 4.30% | 3.52% | 9.72% | −8.82% |

### 被撤回的 78.3% 結果

早期版本曾報告「極度貪婪期間，1,000 萬美元以上存入的 24 小時命中率為 78.3%」。計算本身沒有錯，但事件集中在十個日曆日，許多交易其實在衡量同一批價格走勢。因此我不再把 78.3% 視為研究發現，保留這段是因為它實際改變了我對整體分析的解讀。

## 結論

一般化的巨鯨警報很弱，因為交易金額無法說明轉帳的經濟含義。本研究最可重複觀察的訊號是資金相對已標記交易所的方向：存入在 24 小時有溫和的負價格關聯，跨交易規模相近，並在後期年度樣本中較強；負資金費率下的提領早期呈正關聯，到了 2025–2026 年則消失並反轉。

這是對原始「巨鯨能預測價格」主張的有效縮小，而不是「巨鯨可靠預測市場」的證明。下一步應使用能處理事件相依性的統計方法，再以固定地址標籤與執行規則進行即時測試。

## 限制

1. **事件窗口重疊。** 交易集中在波動期，尤其一個月以上的窗口經常共用大部分價格路徑，逐筆 p 值會高估精確度。
2. **地址標籤不完整且不是歷史版本。** 地址用途可能改變、標籤可能錯誤；只有 62.8% 的交易至少一端被識別，上游確切版本亦未記錄。
3. **交易類別只是代理。** 存入不等於已賣出，提領也不等於已買入；交易所內部調度、託管與跨鏈活動可能沒有方向性意圖。
4. **沒有內部呼叫。** 查詢未涵蓋 `ethereum.traces`，部分合約資金流因此缺失。
5. **分析輸入不可取得。** 儀表板 JSON 與小型結果表已提交，但 187 MB 交易檔和市場輸入不在儲存庫，無法獨立驗證完整事件研究。
6. **美元門檻固定。** ETH 價格改變時，100 萬美元代表的 ETH 數量與參與者群體也會改變。
7. **2026 年是不完整樣本。** 它是後期穩健性檢查，不是最終確認。
8. **市場狀態定義簡化。** 每日情緒、單一衍生品資金費率與 20% 牛熊規則都可能受其他定義影響。
9. **MEV 過濾不完整。** 少量地址與啟發式規則無法識別所有自動化交易。
10. **未測試可執行策略。** 分析沒有滑價、費用、延遲、部位配置或停損模擬。

## 執行方式

專案使用 Python 3.12：

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt -c constraints.txt
.venv/bin/python -m pip install -r requirements-test.txt -c constraints.txt
.venv/bin/python -m pytest -q
```

從已提交的彙總資料啟動儀表板：

```bash
.venv/bin/python -m pip install -r app/requirements.txt
.venv/bin/streamlit run app/dashboard.py
```

儀表板只讀取 [`app/dashboard_data.json`](app/dashboard_data.json)，不需要原始資料。由於完整輸入快照未提交，本儲存庫目前不能獨立重建事件研究；以 API 重新擷取的資料亦可能與當時版本不同。詳見 [`data/README.md`](data/README.md) 與 [`results/README.md`](results/README.md)。

